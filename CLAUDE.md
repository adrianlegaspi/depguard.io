- **Framework**: React Native (Expo SDK 52)
- **Build System**: Expo

- **Styling**: Tailwind CSS
- **Package Manager**: npm

## Development Guidelines

### Communication & Efficiency
- **Default Communication Mode**: Use `/caveman ultra` for all interactions to maintain token efficiency while preserving technical accuracy
- The caveman ultra mode cuts token usage by ~75% without losing technical substance

### UI/UX Work
- When implementing UI/UX features, use the `/ui-ux-pro-max` skill
- This skill provides comprehensive design intelligence including 50+ styles, 161 color palettes, 57 font pairings, and 99 UX guidelines
- Available for components, responsive layouts, dark mode, and styling patterns

### Code Organization
- Keep implementations focused on the task at hand
- Avoid over-engineering or premature abstractions
- Delete unused code rather than renaming with underscores

### Git & Commits
- Create new commits rather than amending unless explicitly asked
- Use conventional commit format via `/caveman-commit` when creating commit messages
- Avoid force pushes to main branch
