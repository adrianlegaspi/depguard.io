# depguard.io Skills Guide

## Active Skills

### 1. caveman (Ultra Mode) — DEFAULT
**Usage**: `/caveman ultra`

**When to Use**: Every interaction (default mode for this project)

**Purpose**: Ultra-compressed communication that cuts token usage ~75% while maintaining full technical accuracy

**Intensity Levels Available**: lite, full, ultra (ultra is the project default), wenyan-lite, wenyan-full, wenyan-ultra

**Reference**: The caveman skill is designed to speak like caveman while keeping full technical accuracy, using shorter statements and minimal fluff.

---

### 2. ui-ux-pro-max — FOR UI/UX IMPLEMENTATIONS
**Usage**: `/ui-ux-pro-max`

**When to Use**: 
- Building or implementing user interfaces
- Designing responsive layouts
- Adding accessible components (dialogs, dropdowns, forms, tables)
- Customizing themes, colors, or dark mode
- Creating design systems
- Optimizing UI/UX patterns

**Capabilities**:
- 50+ UI styles (glassmorphism, claymorphism, minimalism, brutalism, neumorphism, bento grid, dark mode, etc.)
- 161 color palettes
- 57 font pairings
- 99 UX guidelines
- 25 chart types
- 10 design stacks (React, Next.js, Vue, Svelte, SwiftUI, React Native, Flutter, Tailwind, shadcn/ui, HTML/CSS)

**Actions**: plan, build, create, design, implement, review, fix, improve, optimize, enhance, refactor, check

**Projects**: website, landing page, dashboard, admin panel, e-commerce, SaaS, portfolio, blog, mobile app

**Elements**: button, modal, navbar, sidebar, card, table, form, chart

---

## Supporting Skills (Available as Needed)

- **caveman-commit**: Auto-triggered for commit messages or use `/caveman-commit` explicitly
- **caveman-review**: For code review feedback via `/caveman-review`
- **update-config**: For modifying settings.json or hooks configuration
- **security-review**: For security audit of pending changes
- **review**: For PR reviews

## Examples

### Starting a Task (Caveman Ultra)
```
User: Build a login form for the app
Assistant: [invokes /caveman ultra automatically]
```

### UI/UX Implementation
```

Assistant: [invokes /ui-ux-pro-max for design guidance]
```

```
User: I'm ready to commit these changes
Assistant: [invokes /caveman-commit if staging detected]
```
